1. ZIP'i aç.
2. İçindeki dosyaları SoftBridge-Scout-FM26 proje ana klasörüne kopyala.
3. docs/KOYEB-NEON-DEPLOYMENT.md dosyasını sil.
4. GitHub'a yükle.
5. Railway'de New Project > Deploy from GitHub repo seç.
6. Dpehect/SoftBridge-Scout-FM26 reposunu seç.
7. Railway Variables alanına .env.railway.example içindeki değişkenleri gerçek değerlerle ekle.
8. Settings > Networking > Generate Domain seç.
9. /health adresini açarak backend'i kontrol et.
10. Vercel'e NEXT_PUBLIC_API_URL=https://RAILWAY_DOMAIN/api ekle ve yeniden deploy et.
