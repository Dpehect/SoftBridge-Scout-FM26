GUVENLI KURULUM

1. ZIP'i açın.
2. İçindeki Dockerfile, render.yaml ve src klasörünü GitHub reposunun köküne sürükleyin.
3. Sorulduğunda mevcut dosyaların üzerine yazın.
4. Başka dosya silmeyin.
5. Render Environment bölümünde ConnectionStrings__DefaultConnection mevcut Neon bağlantınız olarak kalmalıdır.
6. Render otomatik deploy başlatır.
7. Önce /health kontrol edin. Bu endpoint 200 dönüyorsa servis deploy olmuştur.
8. Sonra /health/db kontrol edin. Bu endpoint veritabanı bağlantısını doğrular.

NOT: Veritabanı geçici olarak bağlanamazsa API yine açılır; Render deploy tamamen düşmez.
