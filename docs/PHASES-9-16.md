# Phases 9–16
- Phase 9: protected admin API, articles and collections management, audit logs.
- Phase 10: dynamic wonderkid, hidden gem, free-agent and expiring-contract collections.
- Phase 11: article API, guide pages, sitemap and robots metadata.
- Phase 12: tactic entity, save/analyze endpoints and visual planner.
- Phase 13: persistent shortlists, notes, public share codes and owner isolation.
- Phase 14: operations dashboard endpoint and aggregate counters.
- Phase 15: response compression, API rate limiting, database indexes and server caching boundaries.
- Phase 16: health checks, CI workflow, production environment documentation and smoke-test foundation.

## Security note
The current admin surface uses a server-only API key for a low-cost first release. Replace it with ASP.NET Identity/OIDC before multi-admin commercial use.
